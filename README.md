# Estimated Inadequate Protein Intake Worldwide

This repository contains the analysis code for the manuscript:

**Estimated Inadequate Protein Intake Worldwide** *(under review)*  
Giacomo De Nicola, Ty Beal, Stella Nordhagen, Stuart M. Phillips, Simone Passarelli, Christopher D. Golden

The analysis estimates the prevalence of inadequate protein intake across 185 countries in 2018, disaggregated by sex and age group. It combines modeled dietary intake data, protein requirement thresholds, caloric intake scenarios, intake distribution parameters, food supply data, body-weight data, and population estimates to reconstruct country-sex-age-specific protein and energy inadequacy.

## Overview

Protein inadequacy is estimated using a probabilistic framework. For each country-sex-age stratum, the analysis reconstructs mean protein intake, specifies an intake distribution, applies a protein requirement threshold, and estimates inadequacy as the probability that intake falls below that threshold.

The analysis has two main components.

First, we estimate protein intake under an **energy-adequate counterfactual**, where each stratum is assumed to consume energy equal to its Estimated Energy Requirement (EER). This isolates the role of dietary protein density from total energy insufficiency.

Second, we estimate protein and energy inadequacy under **realistic caloric intake scenarios**, where country-level caloric intake is derived from FAO Food Balance Sheet energy supply adjusted for modeled downstream food waste.

The main results show that global protein inadequacy based on Estimated Average Requirement (EAR) thresholds is uncommon relative to energy inadequacy, but is geographically and demographically concentrated. Additional analyses evaluate higher function-oriented protein thresholds and a protein-quality adjustment based on the share of protein derived from animal-source foods.

## Analytical workflow

The main scripts are intended to be run in numerical order.

```text
1 -> 2 -> 3 -> 4 -> 5 -> 6
                    -> 7
                    -> 8
                    -> 999
```

The core data-production chain is:

```text
Scripts 1-4
  produce final protein and energy inadequacy estimates

Script 5
  adds protein-source composition and quality-adjusted EAR thresholds

  produces clean supplementary tables

```

## Main analysis scripts

### `1_main_protein.R`

Assembles the main protein intake and requirement inputs. This script harmonizes GDD protein intake data, body-weight data, population data, and protein requirement thresholds by country, sex, and age group.

### `2_protein_inadequacy_under_optimal_caloric_intake.R`

Estimates protein intake under an energy-adequate counterfactual, where energy intake is set equal to each stratum's Estimated Energy Requirement.

### `3_caloric_intake_estimation.R`

Constructs low, central, and high caloric intake scenarios from national food supply data adjusted for modeled downstream food waste.

### `4_caloric_and_protein_inadequacy_calculation_and_overlap.R`

Combines protein and calorie inputs, reconstructs absolute protein intake under modeled caloric intake, disaggregates energy requirements to country-sex-age strata, and estimates protein and calorie inadequacy.

### `5_protein_composition.R`

Estimates the share of dietary protein derived from animal-source foods and seafood using GDD food-group intakes mapped to representative protein densities from USDA FNDDS. It also creates quality-adjusted protein EAR thresholds.

### `6_output_figures.R`

Produces the final manuscript figures.

### `7_create_supplementary_tables.R`

Produces clean supplementary tables.

### `8_dataverse_tables.R`

Produces Dataverse-ready CSV, RDS, and Excel exports.

### `999_extra_visualizations_and_analyses.R`

Produces archived exploratory plots and additional visualizations. This script is not required for the main manuscript pipeline.

## Reproducing the analysis

Because the `data/` folder is not tracked in Git, the full analysis can only be reproduced after obtaining the required input data and placing them in the expected folder structure.

Once the data folder is available, run the scripts from the project root in numerical order:

```r
source("scripts/1_main_protein.R")
source("scripts/2_protein_inadequacy_under_optimal_caloric_intake.R")
source("scripts/3_caloric_intake_estimation.R")
source("scripts/4_caloric_and_protein_inadequacy_calculation_and_overlap.R")
source("scripts/5_protein_composition.R")
source("scripts/6_output_figures.R")
source("scripts/7_create_supplementary_tables.R")
source("scripts/8_dataverse_tables.R")
```

The optional archived script can be run separately:

```r
source("scripts/999_extra_visualizations_and_analyses.R")
```
